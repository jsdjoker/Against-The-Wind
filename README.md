Against The Wind

Against The Wind is a fast-paced 3D endless runner built with Unity.

Run across a dangerous floating path, avoid obstacles, survive falling rocks, and try to stay alive as long as possible. The challenge gets harder as you progress — how long can you survive?

How to Play

Your goal is simple:

Survive for as long as possible.

Avoid obstacles and falling objects while moving through the continuously generated environment.

Built With
1. Unity 6
2. C#
3. Unity Cinemachine
4. TextMeshPro
5. Unity Physics System
6. Unity Audio System
